## Independent review needing remediation before delivery

Read artifacts/independent-review.txt, generated by the independent read-only Codex review. Verify and fix each real remaining finding with regressions (source has evolved; don't blindly apply stale line numbers):
1. Registered read_buf/write_buf return ENOTSUP; libfuse dispatcher prefers these over read/write => ordinary mounted I/O broken. Implement proper buffers or preserve fallback by leaving unsupported ones unregistered; callback-count must not break functionality.
2. Export pwrite positive short count with errno0 becomes false success => snapshot corruption. Loop partial writes/retry EINTR and never promote incomplete export. Regression injection.
3. Native callback exceptions (100000inode limit bad_alloc, others) escape into C ABI and kill helper. Contain ALL callback boundaries and return ENOMEM/ENOSPC, retaining unsaved sentinel.
4. Rollback/restore lstat absence + rename TOCTOU overwrites competing files. Atomic no-replace rename (Darwin RENAME_EXCL).
5. Absolute-path recovery operations follow substituted symlink ancestors after checkedIdentity. Anchor checked directory descriptors, open ancestors nofollow, identity fstat and renameatx_np exclusions; do not mutate substitute directories.
6. setattr_x/fsetattr_x ENOTSUP blocks working fallback; implement correctly or ENOSYS fallback, including handle-only ftruncate after unlink.
7. Unaccounted namespace/hardlink/handle/directory-snapshot allocations can grow withoutbound despite ceiling/node cap. Bound metadata budget/entries/handles, errors not process death.
8. Supported UF_HIDDEN/UF_NODUMP accepted but lost export/import, manifest doesn't verify st_flags. Preserve supported flags through roundtrip and verification. Reject unsupported immutable/append rather than fake support.
