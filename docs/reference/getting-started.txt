Getting Started
What does RAM Folder do?
It turns any folder on your Mac into a RAM folder:
the same folder, at the same path, whose contents now live in memory.
Apps keep using the usual path, but reads and writes run at memory speed
and cause no SSD wear.
When you eject the RAM folder (or quit the app, or shut down
normally), its contents are saved back into the folder, so nothing is
lost between sessions. Our macOS RAM
Disks guide covers how this compares with classic RAM disks, and Synchronization explains how the saving
works.
What do I need to run it?
A Mac running macOS 15 Sequoia or later. RAM Folder
relies on tmpfs, the memory filesystem introduced in macOS 15.
Why
does RAM Folder ask for two permissions at first launch?
Mounting a filesystem requires administrator privileges. RAM Folder
therefore installs a small background helper that does
only that: mount and unmount RAM folders (and save them when they are
ejected while the app is closed). Everything else runs as your normal
user.
The Welcome to RAM Folder window walks you through
two steps. Both must be green to continue:
- Allow the helper daemon. Click Open Login
Items & Extensions, then allow the entry named RAM
Folder to run in the background.
- Grant Full Disk Access. Mounting on top of an
existing folder requires Full Disk Access for the helper. Click
Open Full Disk Access, drag the helper into the list
(or use the + button), and turn it on.
The window checks each step automatically; click
Recheck if it hasn’t noticed a change yet. If the Full
Disk Access step stays red although you have granted it, use
I’ve granted access.
You can review both later in System Settings › General ›
Login Items & Extensions and System Settings ›
Privacy & Security › Full Disk Access.
Why does the helper
need Full Disk Access?
macOS protects many folders (Desktop, Documents, Downloads, iCloud
Drive, other apps’ data…). Mounting a RAM folder on top of one of them
is blocked unless the process doing the mount has Full Disk Access. The
helper uses it only to mount and unmount the folders you choose.
A few locations stay off-limits even with Full Disk Access: see Troubleshooting.
What
is the difference between menu-bar mode and Dock mode?
Choose between them with Show in menu instead of
Dock, in the settings popover (the gear button in the main
window’s toolbar).
- Dock mode (default): RAM Folder behaves like a
regular app, with a Dock icon. Closing the main window quits the app,
saving any mounted RAM folders first.
- Menu-bar mode: RAM Folder lives in the menu bar,
without a Dock icon. Closing the main window leaves the app and your RAM
folders running. The menu-bar panel lists each RAM folder with its state
and a Mount / Unmount button, plus New RAM Folder…,
Open RAM Folder and Quit.
How do I have
my RAM folders ready when I log in?
Turn on Open at login in the settings popover. At
login, RAM Folder starts and mounts every RAM folder whose Mount
at launch option is on (it is on by default). Each one is
refilled from its folder, so you find your files exactly where you left
them.
Combined with menu-bar mode, this happens without any window
opening.
Do my RAM folders
come back after a reboot?
Their contents do, provided they were saved. RAM is cleared at every
restart. But with Sync RAM folder on (the default), a
normal restart or shutdown quits RAM Folder, which saves every mounted
RAM folder into its folder first. At the next login, Open at
login and Mount at launch remount them and
load the saved files back into RAM.
A power cut or a kernel panic runs no save. See Data safety for exactly what survives.
How do the trial and the
license work?
The first 14 days are a free trial with every
feature. After that, a license is needed to keep creating and mounting
RAM folders. See Trial &
license.
How do I update RAM Folder?
RAM Folder checks for updates automatically and offers to install new
versions. You can also choose RAM Folder › Check for
Updates…. Updates never touch your RAM folders’ contents,
folders or snapshots.
Does RAM Folder collect
data about me?
After setup, RAM Folder asks whether to help developers by
sharing analytics data: crash reports and anonymous
feature-usage events. You can change your choice at any time in the
settings popover. When it is off, nothing is sent. Your files’ contents
and names are never sent either way. See our privacy
policy.
How do I
get help, report a bug or suggest a feature?
From the Help menu:
- Online Help Center opens this site.
- Submit Feedback… opens a short survey.
- Ask a Question… opens a new discussion on
GitHub.
- Submit a Feature Request / Bug Report… opens the
GitHub issues page.
